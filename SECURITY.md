# Security policy

petsitter reads files that hold your prompts, code and, for opencode, a local
service password. Security reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/reremint/petsitter/security/advisories/new)
instead. You will get an answer within a few days.

## Supported versions

Only the latest release receives fixes.
